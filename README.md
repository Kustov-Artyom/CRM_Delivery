## Требования

- Node.js 22.13 или новее. Проект использует встроенный модуль `node:sqlite`.
- npm.

## Локальный запуск

Откройте PowerShell в корне проекта и выполните команды в одной сессии:

```powershell
npm install
$key = node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
$env:INVITATION_ADMIN_KEY = $key
Write-Output "Ключ администратора: $key"
npm run dev
```

Откройте `http://127.0.0.1:5173`. Команда `npm run dev` запускает Vite и Express API; Vite перенаправляет запросы `/api` на порт 3001. Введите показанный ключ в разделе администрирования, чтобы создавать приглашения и загружать их историю. Ключ хранится только в памяти страницы. Не публикуйте его и не сохраняйте в репозитории.

## Приглашения и аккаунты

Срок действия приглашения выбирается из вариантов 24 часа, 7 дней и 30 дней. Каждому аккаунту назначается фиксированная роль «Логист». Токены генерируются криптографически стойким способом; в SQLite сохраняется только SHA-256-хеш токена. Погашение приглашения создаёт пользователя и помечает приглашение использованным в одной транзакции.

Email пользователя служит логином. Пароли хранятся как scrypt-хеши, а не в открытом виде. При входе сервер проверяет email и пароль по данным SQLite.

## Данные и карта

По умолчанию база SQLite создаётся в `data/crm.sqlite`; каталог исключён из Git. Путь можно изменить переменной `SQLITE_PATH`, порт API — переменной `API_PORT`.

Для геокодирования и прокладки маршрутов карта обращается к Nominatim и OSRM, а подложку загружает с OpenStreetMap. Для полной работы карты требуется доступ к этим сервисам через интернет.

## Проверки

```powershell
npm run build
```

`npm test` запускает API-тесты Express и SQLite на временной базе в памяти и не изменяет `data/crm.sqlite`.
